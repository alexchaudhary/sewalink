# Desktop App Scaffold

This folder is reserved for the Electron desktop application.

## Recommended stack

- Electron
- React
- TypeScript
- Tailwind CSS
- Socket.io client

## Initial commands

```bash
cd desktop
npm init electron-app . -- --template=typescript
```

## Purpose

Use this package to create a desktop wrapper for the web experience with offline-ready assets, native notifications, and local persistence.
