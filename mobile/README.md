# Mobile App Scaffold

This folder is reserved for the React Native / Expo mobile application.

## Recommended stack

- Expo
- React Native
- TypeScript
- React Navigation
- Redux Toolkit / Zustand
- Socket.io client for realtime chat and booking updates
- Google Maps React Native integration

## Initial commands

```bash
cd mobile
npx expo init sewalink-mobile --template expo-template-blank-typescript
```

## Key screens

- Welcome / auth
- Search providers
- Provider profile
- Booking checkout
- Chat and notifications
- Customer dashboard
- Provider dashboard
